Financial Statement Automation System — interview notes

ACCOUNTING
Why does a balance sheet balance? Assets are financed by liabilities or owners' equity, so assets = liabilities + equity. An imbalance signals an error or incomplete data.
Why can profit coexist with negative cash flow? Revenue and expenses are recorded on an accrual basis. Cash can be tied up in receivables or inventory, or spent on capital assets.
What is working capital? Current assets minus current liabilities. It is a short-term liquidity measure, though its meaning depends on the business.
What is depreciation? Allocation of an asset's cost over its useful life. It reduces accounting profit without being a current cash payment.
How do the statements connect? Net income flows into equity and starts the indirect operating cash flow reconciliation. Cash flow explains the change in balance sheet cash.

FINANCIAL ANALYSIS
Gross margin: (revenue - cost of revenue) / revenue. It shows what remains after direct costs.
ROA versus ROE: Return on assets uses all assets; return on equity uses owners' capital. Leverage can raise ROE without improving asset productivity.
Why average balance sheet amounts? Sales and profit cover a period, while assets and equity are point-in-time balances. Averaging opening and closing values is a better match.
DSO: Days sales outstanding estimates how long customer collections take, using receivables / revenue times days in period.
Cash conversion cycle: DIO + DSO - DPO. It estimates the time between paying suppliers and collecting customers.
Free cash flow: Operating cash flow less capital spending. This project stores capital expenditure as a signed cash outflow, so it adds that negative amount to operating cash flow.
Growth percentages can mislead when the base is near zero, negative, or not comparable. The app marks unsafe comparisons unavailable.

DATA ENGINEERING
Preserve original data so every normalized value can be checked against the source and corrections can be audited.
Keep extraction separate from normalization: reading a cell is a different decision from interpreting its unit, period, or financial meaning.
Store original and canonical labels: the first shows what the file said; the second lets the application compare equivalent lines across sources.
Page, sheet, and cell references let a reviewer trace a number and investigate mistakes.
Units matter because “1,000 in millions” is not 1,000 actual currency units. The app requires a confirmed scale and does no currency conversion.

SOFTWARE
FastAPI provides typed Python routes around the extraction and finance code. Next.js serves the interface and protected workspace. Supabase supplies Auth, Postgres, Storage, and row security.
RLS limits each signed-in user's database reads. The server also checks ownership before using its privileged key.
Direct-to-storage upload keeps large files off Vercel request bodies. Serverless work still has time and memory limits, so long-running jobs would need a separate worker later.
Finance formulas need hand-verifiable tests because a plausible but wrong ratio can be more dangerous than a visible error.

SECURITY
A service-role or secret key is privileged server-only access and can bypass RLS. Putting it in browser code would expose other users' data.
RLS protects database rows even if a client calls Supabase directly. Private Storage prevents public file URLs; signed links are short-lived.
Cross-user access is blocked by RLS and by owner filters in API queries. Tests cover anonymous requests and attempts by a second user ID.

AI
An LLM may explain accepted calculations but is not the source of figures or formulas. The app derives numbers with deterministic code, supplies provenance, and falls back to fixed explanations if the model is unavailable.
